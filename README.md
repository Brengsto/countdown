# Countdown

A blackjack and card counting trainer: basic strategy, Hi-Lo counting against the dealer, true count, a full game table and an EV simulator.

**Download page:** https://brengsto.github.io/countdown/

- Windows: get the installer or the portable version from [Releases](https://github.com/Brengsto/countdown/releases/latest).
- Mac, Linux, tablet: [play in your browser](https://brengsto.github.io/countdown/play.html).

The Windows files aren't digitally signed, so Windows shows a warning. Click **More info**, then **Run anyway**.

Countdown is a training program and doesn't guarantee winnings.
